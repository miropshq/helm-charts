# Contributing to helm-charts

Thanks for your interest in the mirops Helm charts — this repository ships the `mirops-operator` chart
that deploys the operator into a cluster. Contributions of all kinds are welcome: bug reports, chart
fixes, and docs.

By participating you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## The ecosystem

mirops is a few repositories that work together:

| Repo | What it is |
| --- | --- |
| **mirops** | The operator (Go, controller-runtime) — collector, mirror engine, scoring, decision. |
| **mirops-headlamp-plugin** | The Headlamp plugin (React/TS) that visualizes the report. |
| **mirops-cli** | CLI to run/enforce an analysis in CI. |
| **helm-charts** (this repo) | The `mirops-operator` Helm chart. |
| **mirops-compat** | The community add-on ↔ Kubernetes compatibility matrix. |

## Getting started

Prerequisites: [Helm](https://helm.sh) 3 and `kubectl`.

```bash
helm lint mirops-operator
helm template mirops-operator | kubectl apply --dry-run=client -f -
```

> **CRDs** are generated by the operator's CI (`make manifests`) and consumed as an artifact — they
> should match the operator version, so avoid hand-editing the CRDs in this repo.

## Making a change

1. **Fork** and branch from `main` (`feat/…`, `fix/…`).
2. Keep the change focused. Bump `Chart.yaml`'s `version` for chart changes; keep `appVersion` in sync
   with the operator image you target.
3. Run `helm lint` and a `helm template` dry-run against a cluster before pushing.
4. Open a PR.

### Commit & PR conventions

This project uses **[Conventional Commits](https://www.conventionalcommits.org/)**:

```
feat: …      # a new feature (minor)
fix: …       # a bug fix (patch)
docs: …      # documentation only
chore: …     # tooling/CI
```

A breaking change adds a `!` (`feat!: …`) or a `BREAKING CHANGE:` footer (major).

## Reporting bugs & requesting features

Open an issue with what you expected, what happened, your Helm/Kubernetes versions, and the values you
installed with (redacted). For security issues, **do not** open a public issue — see
[SECURITY.md](SECURITY.md).
